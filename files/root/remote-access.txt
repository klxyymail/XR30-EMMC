========================================
 从外网连回家里内网（WireGuard）
========================================

刷完固件、路由器拨号上网后，系统已经自动完成：

  [√] 建好 WireGuard 服务端接口 wg0（10.66.66.1/24，UDP 51820）
  [√] 生成服务端密钥（/etc/wireguard/server.key）
  [√] 配好防火墙：vpn 区域 + 双向转发 + WAN 放行 UDP 51820
  [√] WAN 拨号成功后自动生成客户端 phone 的配置

------------------------------------------------
一、最快路径：手机扫码导入
------------------------------------------------
1. 手机连家里 WiFi
2. 浏览器打开：http://192.168.6.1/wg/phone.png
3. 用 WireGuard App 扫二维码（应用商店搜 WireGuard）
4. 首次连接前，确认家里宽带有公网 IPv4（见第三节）

配置文件同时存放在：
  /etc/wireguard/clients/phone.conf
  /etc/wireguard/clients/phone.png

------------------------------------------------
二、常用命令（SSH 到路由器执行）
------------------------------------------------
  wg-client list               看已有客户端
  wg-client add ipad           再加一台设备（全流量回家）
  wg-client add tv lan         只让这台设备访问家里内网
  wg-client endpoint 你的域名   固定 DDNS 域名
  wg show wg0                  看隧道状态和握手时间

  sh /root/xr30-wireguard-setup.sh    整个重来一遍（可改端口/网段/多客户端）

------------------------------------------------
三、连不上时按顺序排查
------------------------------------------------
1) 家里有没有公网 IPv4？
   执行：wg-client add phone
   若提示「探测到的 x.x.x.x 是内网/CGNAT」，说明运营商没给公网 IP。
   解决办法：
     A. 打运营商客服申请公网 IPv4（说需要远程访问 NAS/监控）
     B. 光猫改桥接，路由器 PPPoE 拨号
     C. 实在拿不到，用固件内置的 ZeroTier：
        LuCI -> VPN -> ZeroTier，填 Network ID 即可，不需要公网 IP

2) 光猫/上级路由要放行 UDP 51820 到路由器
   光猫做 DMZ 指向路由器 WAN IP，或加一条端口映射 UDP 51820

3) 动态 IP 建议配 DDNS
   LuCI -> 服务 -> 动态 DNS，绑定一个域名（如 xxx.3322.org）
   然后执行：wg-client endpoint xxx.3322.org

4) 看握手时间判断通不通
   wg show wg0 latest-handshakes
   时间戳接近现在 = 通了；为 0 = 不通（端口/防火墙/地址问题）

------------------------------------------------
四、安全提示
------------------------------------------------
- 导入二维码后，建议删掉网页上的二维码文件：
    rm -f /www/wg/*.png
- 固件默认 root 密码为空，建议在 LuCI -> 系统 -> 管理权 里设置密码
- WireGuard 基于密钥认证，端口被扫到也无法接入，但密钥不要外传
